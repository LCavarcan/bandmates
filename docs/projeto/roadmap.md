# Roadmap

## ✅ Fase 1: estrutura funcional

- [x] Projeto com TypeScript, React, Vite e Vitest.
- [x] Quatro integrantes com habilidades, traços e estados emocionais.
- [x] Atividades semanais e avanço do tempo.
- [x] Resumo semanal com falas próprias.
- [x] Relações em dupla.
- [x] Salvamento local versionado.

## ✅ Fase 2: ciclo musical

- [x] Conceito da música: gênero, tema, direção e líder.
- [x] Reações da banda às escolhas musicais.
- [x] Composição com líder e arranjadoras.
- [x] Atributos: qualidade, originalidade, apelo, coesão, identidade.
- [x] Ensaio como lapidação da próxima faixa.
- [x] Gravação (atividade com custo) e nota final.
- [x] Lançamento, recepção e streaming com decaimento.
- [x] Identidade artística da banda.

## ✅ Fase 3: personagens e relações

- [x] Sistema de eventos orientado a dados (condições, escolhas, desfechos condicionais).
- [x] 9 eventos principais e 4 continuações, escritos à mão.
- [x] Flags e continuações agendadas com consequências futuras.
- [x] Conversa da semana (três abordagens, respostas por personagem).
- [x] Consequências nas ações musicais: modificadores de atividade, bônus na música, entrosamento na gravação.

## ⏳ Fase 4: campanha

- [ ] Shows locais (renda principal, preparo, setlist).
- [ ] Objetivo: a seletiva do festival na semana 12.
- [ ] Arco romântico opcional (sáfico), gradual e recíproco.
- [ ] Finais com base no que a banda construiu.

## Fase 5: persistência e polimento

- [ ] Refino de interface e retratos.
- [ ] Mais testes e correções.
- [ ] Executável para Windows (ferramenta gratuita, a avaliar).
- [ ] Instruções de distribuição.

## Fora do MVP

Multiplayer, mundo aberto, recrutamento ilimitado, várias cidades, editor de músicas, geração de áudio, vozes sintetizadas, IA generativa, loja extensa, decoração de estúdio, contratos complexos, serviços online e contas.

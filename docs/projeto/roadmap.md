# Roadmap

## ✅ Fase 1: estrutura funcional

- [x] Projeto com TypeScript, React, Vite e Vitest.
- [x] Quatro integrantes com habilidades, traços e estados emocionais.
- [x] Atividades semanais e avanço do tempo.
- [x] Resumo semanal com falas próprias.
- [x] Relações em dupla.
- [x] Salvamento local versionado.

## ✅ Fase 2: ciclo musical

- [x] Conceito da música: gênero, tema, direção e líder.
- [x] Reações da banda às escolhas musicais.
- [x] Composição com líder e arranjadoras.
- [x] Atributos: qualidade, originalidade, apelo, coesão, identidade.
- [x] Ensaio como lapidação da próxima faixa.
- [x] Gravação (atividade com custo) e nota final.
- [x] Lançamento, recepção e streaming com decaimento.
- [x] Identidade artística da banda.

## ✅ Fase 3: personagens e relações

- [x] Sistema de eventos orientado a dados (condições, escolhas, desfechos condicionais).
- [x] 9 eventos principais e 4 continuações, escritos à mão.
- [x] Flags e continuações agendadas com consequências futuras.
- [x] Conversa da semana (três abordagens, respostas por personagem).
- [x] Consequências nas ações musicais: modificadores de atividade, bônus na música, entrosamento na gravação.

## ✅ Fase 4: campanha

- [x] Shows em 4 casas (requisitos, intervalo, gênero preferido, setlist com covers, nota, público, cachê).
- [x] Objetivo: a seletiva do Festival Maré Alta na semana 12, com a avaliação do júri.
- [x] 7 metas intermediárias que somam pontos na avaliação.
- [x] Eventos de campanha: *O cartaz*, *Depois do primeiro show*, *Véspera*.
- [x] Arco romântico opcional entre Lia e Nina: sinais dos dois lados, vulnerabilidade, decisão, reciprocidade, amizade como final válido.
- [x] Final com resultado, epílogo por integrante e epílogo do arco.

## ✅ Fase 5: persistência e polimento

- [x] Layout para celular: coluna única, barra de ação no rodapé, modais em tela cheia, áreas de toque maiores.
- [x] Dicas visíveis no toque (antes só apareciam ao passar o mouse).
- [x] Backup do save: exportar e importar arquivo.
- [x] Validação estrutural de saves e proteção contra erros de renderização.
- [x] Testes falham com avisos do React no console.
- [x] Distribuição: `Bandmates.html` em arquivo único, offline, com verificação de URLs externas.
- [x] `npm run dev:rede` para jogar no celular pela rede local.
- [x] Checklist de qualidade.

## Próximos passos possíveis

- [ ] Teste manual completo no PC e no celular (veja o [Checklist de qualidade](qualidade.md)).
- [ ] Arte definitiva dos retratos (a interface já está pronta para trocar).
- [ ] Efeitos sonoros opcionais (licença permissiva).
- [ ] Mais eventos e um segundo arco romântico.
- [ ] Executável `.exe` (Electron ou Tauri), se o arquivo único não bastar.

## Fora do MVP

Multiplayer, mundo aberto, recrutamento ilimitado, várias cidades, editor de músicas, geração de áudio, vozes sintetizadas, IA generativa, loja extensa, decoração de estúdio, contratos complexos, serviços online e contas.
